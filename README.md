# Salesforce Web Clone 🚀

A pixel-perfect front-end clone of the Salesforce website homepage. This project was built from scratch to practice advanced HTML5 and CSS3 techniques, focusing on structure, layout alignment, and clean coding practices.

---

## 🌟 Features
* **Header & Navigation:** Clean implementation of the Salesforce navbar with dropdown links and button styling.
* **Hero Section:** High-quality replica of the main marketing banner, call-to-action buttons, and background layouts.
* **Product Showcase Grid:** Organized layouts displaying various Salesforce services and features.
* **Responsive Design:** (Optional: Agar mobile-friendly banaya hai toh yeh line rakhein, warna delete kar dein) Optimized for desktops, tablets, and mobile devices.

---

## 🛠️ Tech Stack Used
* **HTML5:** For semantic web structuring.
* **CSS3:** For custom styling, Flexbox/Grid layouts, and responsiveness.
